Discover: the AI the company runs, direct and indirect

Agent identities in the CRM’s change history show direct AI: agents that act and write records themselves. SSO, admin and usage data show indirect AI: tools people use, whose effect runs through what those people do.

Build lineage: the coding sessions behind the built bots

A built bot has two costs: running it, and the work that built it. There is no coding assistant: the builders used ChatGPT. Its sessions carry no repo id, so Gnocchi links them to repo commits by team, timing (a commit within 36 hours) and text, then follows the CI deploy that turns that repo into a bot identity, and the CRM records the bot then writes. The bot’s effect from step 7 closes the chain.

Same bot, built twice

Built tools: what building, then maintaining, really costs

Employees vibe-code tools with ChatGPT, and every tool keeps asking for sessions after it ships: API releases, edge cases, timeouts. Gnocchi counts both, so a built tool can be compared fairly with one that is bought. A tool with no repo, deploy or register entry shows up only in session text: one team, the same thing, for months.

The driver model run in reverse. For every driver: the AI on it today, each team’s level, and the gap to the best team in days of cycle per new deal. A driver with weight and no AI is an AI opportunity; a driver whose AI some teams don’t use is an adoption gap.

A
Appendix: did the analysis find what was planted?
The synthetic data carries known effects. Recovering them shows the method works; it says nothing about whether these tools work in a real company.

  





  
About the data. Deals are real and anonymized (owner, account and partner names replaced); they are the full years 2023 and 2024 with every date moved one year later, so the baseline reads 2024 and the AI year 2025. CRM history, OKRs, AI logs and usage are synthetic, generated with a fixed seed. Only closed-won deals exist, so win rate isn’t studied. NA West and APAC are small teams, which widens their ranges.

  
Everything is reported at team level. No person is a unit of analysis.
